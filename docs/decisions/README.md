# Architecture Decision Records (ADR)
Mỗi quyết định thiết kế quan trọng = 1 file ngắn: Bối cảnh → Quyết định → Lý do → Đánh đổi.
Trạng thái: `Proposed` / `Accepted` / `Superseded`. Khi đổi ý, **không xoá** ADR cũ — tạo ADR mới và đánh dấu cái cũ `Superseded`.
Khoa tự điền phần "Lý do bằng lời của Khoa" ở các ADR đánh dấu 🧠.
