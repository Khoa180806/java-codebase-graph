# v1.7 — Live Viewer qua HTTP

## Mục tiêu
Nâng Graph Viewer tĩnh (Phase 7) thành ứng dụng web tương tác: gọi trực tiếp backend, không cần xuất file thủ công.

## Tính năng
- Backend HTTP mỏng (có thể là Spring Boot — nối với Dự án 2) bọc lớp `query`: `GET /api/types?q=`, `/api/types/{fqn}`, `/api/methods/{id}/callers`, `/api/types/{fqn}/impact?depth=`.
- Viewer chuyển sang gọi API; thêm TanStack Query để cache/refetch (khớp roadmap fullstack).
- Chế độ chọn project; trạng thái "đang index"; nút re-index (kết hợp `v1.1`).
- Làm nổi bật cạnh `interface-dispatch` bằng nét đứt; lọc theo loại cạnh; xuất PNG/SVG.

## Task gợi ý
