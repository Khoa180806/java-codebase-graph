# v1.6 — Spring-aware Analysis

## Vì sao
Spring Boot là stack mục tiêu của Khoa (Dự án 2). Graph hiểu Spring sẽ cho kết quả hữu ích hơn và nối 2 dự án lại với nhau.

## Vấn đề cần giải
Code Spring hay inject theo **interface**; graph v1.0 chỉ biết `OrderService → PaymentService`, không biết bean nào thực sự được inject.

## Tính năng
- Nhận diện stereotype: `@Component/@Service/@Repository/@Controller/@RestController/@Configuration`, `@Bean`.
- **Bean wiring tĩnh:** `@Autowired` field / constructor injection → cạnh `INJECTS` (type → bean cài đặt). Nhiều implementation → đánh dấu candidates; xét `@Primary`, `@Qualifier`.
- **Endpoint map:** `@GetMapping/@PostMapping/@RequestMapping` → danh sách endpoint (HTTP method, path, handler method) + chuỗi gọi xuống tới repository.
- **Tool MCP:** `list_endpoints`, `get_bean_graph`, `trace_endpoint(path)` (từ endpoint đi xuống các service/repository).
