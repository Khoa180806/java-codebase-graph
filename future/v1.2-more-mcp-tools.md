# v1.2 — Thêm MCP Tools

## Mục tiêu
Mở rộng bộ công cụ cho agent dựa trên dữ liệu graph đã có (ít cần parse thêm).

## Tool đề xuất
| Tool | Ý nghĩa | Thuật toán |
|---|---|---|
| `find_implementations(type)` | Ai implement/extend type này (trực tiếp + gián tiếp) | reverse EXTENDS/IMPLEMENTS, BFS |
| `find_callees(method)` | Method này gọi gì | forward CALLS |
| `get_call_hierarchy(method, direction, depth)` | Cây gọi lên/xuống | BFS/DFS có depth |
| `find_dependencies(type)` | Type này phụ thuộc type nào | forward USES_TYPE + CALLS |
| `search_symbols(query)` | Tìm type/method theo tên (substring/camelCase) | index chuỗi; bonus: fuzzy |
| `get_project_summary()` | Số type/method, resolve stats, package chính | thống kê |
