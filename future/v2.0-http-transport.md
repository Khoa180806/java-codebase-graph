# v2.0 — HTTP Transport & Multi-project

## Mục tiêu
Chạy server dùng chung (không chỉ stdio cục bộ): nhiều client, nhiều project.

## Tính năng
- Transport HTTP (Streamable HTTP/SSE theo MCP SDK phiên bản mới nhất — kiểm tra spec hiện hành).
- Quản lý **nhiều project** (`project_id`): `register_project(path)`, `list_projects`, mỗi project một graph.
- Xác thực đơn giản (token qua header) + giới hạn path được phép index (allow-list) để tránh đọc thư mục tuỳ ý.
- Đóng gói Docker; cấu hình bằng biến môi trường.
- (Tuỳ chọn) bọc bằng Spring Boot để tái dùng kỹ năng Dự án 2.

## Task gợi ý
- V20-T1 Tách `ProjectRegistry` (Map projectId → CodeGraph snapshot), thread-safe.
- V20-T2 Transport HTTP + cấu hình port.
- V20-T3 Auth token + allow-list path (kèm test path traversal `../`).
- V20-T4 Dockerfile + docker-compose; mount volume chứa source.
- V20-T5 Test đồng thời nhiều client.

## Acceptance
2 client gọi đồng thời 2 project khác nhau, kết quả không lẫn. Path ngoài allow-list bị từ chối.

## Lưu ý bảo mật
Đây là lúc vấn đề đầu vào không tin cậy (đã cắt zip ở v1.0 — ADR-006) quay lại: path traversal, giới hạn kích thước, timeout.
