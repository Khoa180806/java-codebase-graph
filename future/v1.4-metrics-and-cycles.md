# v1.4 — Metrics & Cycle Detection

## Mục tiêu
Từ graph, rút ra thông tin kiến trúc có giá trị.

## Tính năng
- **Dependency cycles** giữa package/type: thuật toán **Tarjan SCC** (tự cài để học; xem lại ADR-002).
- **Fan-in / fan-out** mỗi type (số type phụ thuộc vào / mà nó phụ thuộc) → xếp hạng "hot spot".
- **Dead code candidates:** method không có caller (loại trừ `main`, override interface, test, annotation entry point) — đặt tên là *candidates*, không khẳng định.
- **Layer rule check (tuỳ chọn):** file cấu hình `rules.yml` (vd `controller` không được gọi `repository` trực tiếp) → liệt kê vi phạm.
- Tool MCP: `find_cycles`, `get_hotspots`, `find_dead_code_candidates`, `check_layer_rules`.
